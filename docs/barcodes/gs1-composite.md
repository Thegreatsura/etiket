# GS1 Composite

A composite symbol is a linear barcode with a 2D component printed above it. The
linear part carries the primary identifier — usually the GTIN — and the 2D part
carries the attribute data that will not fit: batch, expiry, serial, weight.

## When to Use It

- Healthcare packaging that needs GTIN plus expiry and lot in a small footprint
- Variable-measure retail items where the linear symbol must stay scannable at
  the till
- Any GS1 application where the AI data outgrows the linear symbology

## Component Types

| Type   | Built on    | Capacity | Typical use                       |
| :----- | :---------- | :------- | :-------------------------------- |
| `CC-A` | MicroPDF417 | Small    | A few short AIs                   |
| `CC-B` | MicroPDF417 | Medium   | Batch, expiry and serial together |
| `CC-C` | PDF417      | Large    | GS1-128 primaries with bulk data  |

## Usage

```ts
import { encodeGS1Composite } from "etiket"

const result = encodeGS1Composite("(17)260101(10)BATCH01", "CC-A")
result.type // "CC-A"
result.rows // 14
result.cols // 55
result.composite // boolean[][] — the 2D component
```

The type defaults to `CC-A`:

```ts
import { encodeGS1Composite } from "etiket"

encodeGS1Composite("(10)BATCH01").type // "CC-A"
```

## Rendering a Composite Symbol

There is no single function that emits a complete composite symbol: you render
the 2D component and the linear component separately and stack them, because the
alignment and the separator belong to your label layout.

```ts
import { encodeGS1Composite, barcode, renderMatrixSVG } from "etiket"

const composite = encodeGS1Composite("(17)260101(10)BATCH01", "CC-A")

const top = renderMatrixSVG(composite.composite, { size: 200, margin: 0 })
const bottom = barcode("(01)09501101020917", { type: "gs1-128", showText: true })

// Place `top` directly above `bottom`, left-aligned, in your own layout
top.startsWith("<svg") // true
bottom.startsWith("<svg") // true
```

The primary linear symbol is an ordinary [GS1-128](/barcodes/gs1-128) or
[GS1 DataBar](/barcodes/gs1-databar) symbol — encode it as you normally would.

## Caveats

- **The linkage flag is not set.** A conformant composite marks the linear
  component so a reader knows to look for a 2D component above it; etiket
  produces the 2D component as a standalone symbol and leaves the linear one
  untouched. A reader will decode both parts, but not as a linked pair.
- The composite component is generated by encoding the AI string directly through
  MicroPDF417 or PDF417. It does not implement the CC-A specific base-928
  encodation of the GS1 General Specifications.
- CC-A and CC-B differ only in the MicroPDF417 column count (2 and 3); CC-C is
  PDF417 at EC level 2 with 4 columns. There is no automatic promotion from one
  type to the next when the data grows — pick the type yourself, or catch
  `CapacityError` and retry with a larger one.
- A parenthesised input is validated as an AI string and raises
  `InvalidInputError` when malformed. Input with no `(` is passed through as raw
  element string data, unvalidated.
- An unknown composite type raises `InvalidInputError`; empty data does too.

Given those limits, treat this as the encoder for the 2D component rather than a
complete composite-symbol implementation.
